# Агенты разработки VoiceCRM

Восемь профилей для команды, которая разрабатывает голосовой CRM-проект.
Они используют модель и уровень рассуждения основной сессии Codex.
Профили задают специализацию; качество подтверждается кодом, проверками и замерами.

| Агент | Когда подключать |
|---|---|
| `crm_architect` | Разобрать проект, выбрать следующий этап, спроектировать связь голоса, телефонии и CRM |
| `voice_backend` | Настроить OpenAI, STT, HTTP-маршруты, контекст и обработку ошибок |
| `realtime_audio` | Настроить потоковый разговор, микрофон, воспроизведение и перебивания |
| `latency_qa` | Измерить скорость до звука, проверить ошибки и качество после ускорения |
| `crm_integrations` | Подключить конкретную CRM, сохранять заявки и предотвращать дубли |
| `telephony_engineer` | Подключить телефонный номер, внутренние номера и перевод сотруднику |
| `call_analytics` | Сохранить записи, расшифровать звонки и подготовить проверяемый анализ |
| `knowledge_quality` | Подключить утверждённые сведения компании и проверить ответы администратора |

Например, напишите Codex: «Подключи crm_architect, realtime_audio и latency_qa:
проверь Realtime и измерь время от конца речи до первого звука». Координатор
распределяет задачи и файлы; доступное число параллельных агентов задаёт среда.
Эти профили используются для разработки проекта. Оператор для клиентов появится
после реализации и проверки соответствующих функций приложения.

Исходные профили: `agents/profiles/*.toml`. Codex читает проектные профили из
`.codex/agents/`; [официальная документация подагентов](https://learn.chatgpt.com/docs/agent-configuration/subagents)
описывает поля `name`, `description` и `developer_instructions`.

Проверка формата и установка подготовленных профилей:

```sh
.venv/bin/python scripts/install_project_agents.py --check
.venv/bin/python scripts/install_project_agents.py
# После намеренного обновления исходных профилей: сохранить старые и обновить копии.
.venv/bin/python scripts/install_project_agents.py --update
```

Установка сохраняет восемь файлов в `.codex/agents/` и по умолчанию отказывается
заменять отличающиеся профили. `--update` сохраняет прежние копии в
`data/backups/project-agents-*` перед заменой. В среде, где `.codex` доступен только для
чтения, для установки потребуется разрешение на запись. Настройки модели,
ключи, разрешения и глобальная конфигурация Codex не меняются.

CRM заказчика выбрана и установлена: EspoCRM10.0.9. Ближайшая работа команды —
данные компании, подтверждаемые голосовые действия через её API и живой тест
`/realtime` до первого слышимого звука. Затем — телефония и аналитика по
`docs/ROADMAP.md`.
