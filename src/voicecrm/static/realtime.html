Нужен ключ OpenAI API в локальном .env: OPENAI_API_KEY. После добавления перезапустите сервер и обновите настройки. Ключ не вводится на этой странице.

Последний отклик сервиса: — Ответов: 0 · медиана: — · p95: — Пауза завершения речи: — Расход токенов: —

Например: «Хочу записаться на чистку в пятницу после трёх».

Отклик сервиса измеряется между получением уведомлений о конце реплики и начале аудио OpenAI. Пауза завершения речи и задержка воспроизведения не включены: это не время до первого звука в динамиках. Статистика относится к текущему разговору; прерванные и ошибочные ответы исключаются. При малом числе ответов p95 предварительный. Текст может появиться позже голоса; прерванный ответ мог прозвучать не полностью.

Вы разговариваете с ИИ. Микрофон передаётся напрямую OpenAI только во время подключения. Это платный тест API, каждый разговор автоматически завершается через 5 минут. Используйте вымышленные обращения. Настоящая запись на приём не создаётся. Расшифровка нужна только для экрана — модель отвечает непосредственно на аудио. Для проверки перебиваний рекомендуются наушники.
